Бесплатный AI (Groq)

Зарегистрируйтесь на console.groq.com и получите бесплатный API-ключ. Добавьте его в переменную окружения GROQ_API_KEY.

IMAP-почта (опционально)

Для автоматической загрузки непрочитанных писем задайте переменные окружения:

  • IMAP_HOST — например imap.yandex.ru
  • IMAP_USERNAME
  • IMAP_PASSWORD
  • IMAP_FOLDER — по умолчанию INBOX

Локальный режим

Без API-ключа приложение работает в локальном режиме: определяет категорию по ключевым словам и формирует краткий конспект автоматически.
