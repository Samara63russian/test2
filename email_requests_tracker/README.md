# Трекер входящих запросов

Веб-приложение для отслеживания входящих писем с запросами на **коммерческое предложение (КП)**, **перечень/прайс** или **общие обращения**. AI кратко конспектирует письмо и создаёт запись в базе.

## Возможности

- Классификация писем: КП, перечень, общий запрос
- Краткий AI-конспект на русском языке
- Дашборд со статистикой и фильтрами
- Ручное добавление писем
- Загрузка непрочитанных писем через IMAP (опционально)
- Статусы: новый, в работе, завершён, архив

## Бесплатный AI

Приложение использует [Groq API](https://console.groq.com) — бесплатный тариф с быстрыми моделями Llama.

1. Зарегистрируйтесь на https://console.groq.com
2. Создайте API-ключ
3. Скопируйте `.env.example` в `.env` и укажите `GROQ_API_KEY`

Без ключа работает **локальный режим**: категория определяется по ключевым словам, конспект формируется автоматически.

## Запуск

```bash
cd email_requests_tracker
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env
uvicorn app.main:app --reload --host 0.0.0.0 --port 8080
```

Откройте http://localhost:8080

## IMAP (опционально)

Для автоматической загрузки писем добавьте в `.env`:

```env
IMAP_HOST=imap.yandex.ru
IMAP_USERNAME=your@email.ru
IMAP_PASSWORD=app-password
IMAP_FOLDER=INBOX
```

На дашборде нажмите **«Загрузить из почты»**.

## API

| Метод | Путь | Описание |
|-------|------|----------|
| GET | `/api/requests` | Список записей |
| POST | `/api/requests` | Добавить и проанализировать письмо |
| GET | `/api/requests/{id}` | Детали записи |
| PATCH | `/api/requests/{id}/status` | Обновить статус |
| DELETE | `/api/requests/{id}` | Удалить запись |
| POST | `/api/imap/fetch` | Загрузить письма из IMAP |
| GET | `/api/stats` | Статистика |
