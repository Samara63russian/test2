# CryptoStatte

Премиальный одностраничный сайт криптообменника. Сайт работает без сборки и
сторонних JavaScript-зависимостей.

## Локальный запуск

```bash
python3 -m http.server 8080 --directory cryptostatte
```

После запуска откройте `http://localhost:8080`.

Калькулятор показывает ориентировочный расчёт, переключает направление и сеть,
а затем формирует готовую заявку для менеджера в Telegram.
