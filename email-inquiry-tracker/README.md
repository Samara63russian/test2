# Письмо → Запись

Веб-приложение для отслеживания входящих писем с запросами **коммерческого предложения (КП)**, **перечня / прайса** или обычными обращениями.

## Что делает

1. Принимает письмо (вставка текста или импорт `.eml` / `.txt`)
2. Классифицирует тип запроса
3. Кратко конспектирует содержимое бесплатным ИИ
4. Создаёт карточку в журнале с контактами, срочностью и рекомендуемым действием

## Бесплатный ИИ

| Режим | Ключ | Описание |
|-------|------|----------|
| **Локальный** | не нужен | Работает сразу: эвристики + экстрактивный конспект |
| **Groq** (опционально) | [console.groq.com/keys](https://console.groq.com/keys) | Более точные резюме через Llama 3.1 (бесплатный лимит) |

Ключ Groq хранится только в `localStorage` браузера.

## Запуск

```bash
cd email-inquiry-tracker
npm install
npm run dev
```

Откройте [http://localhost:3000](http://localhost:3000).

## Стек

- Next.js (App Router) + TypeScript + Tailwind
- API `/api/analyze` — анализ письма
- Хранение записей в браузере (`localStorage`)

## Примеры

На форме есть готовые примеры: запрос КП, прайс, общий вопрос и срочный RFQ.
