# Система сводных справок

Веб-приложение и Android-клиент для заполнения форм «вопрос — ответ» по учреждениям и формирования итоговой сводной справки (PDF / Word).

## Возможности

- **Главная** — выбор учреждения, фильтр справок по датам и статусу, открытие и скачивание документа
- **Справочник** — учреждения, типы, районы, должности
- **Аналитика** — количество справок, разрез по учреждениям и месяцам
- **Настройки** (администратор):
  - вопросы и варианты ответов, разделы анкеты
  - логины и пароли пользователей
  - создание и удаление учреждений
  - шапка и название итогового документа
- **Android APK** — быстрое заполнение формы офлайн, выгрузка на сервер при появлении интернета, скачивание PDF

## Быстрый запуск

```bash
cd spravka/backend
pip install -r requirements.txt
PYTHONPATH=. uvicorn app.main:app --reload --host 0.0.0.0 --port 8000
```

В другом терминале:

```bash
cd spravka/frontend
npm install
npm run dev
```

Откройте http://127.0.0.1:5173

Учётные записи по умолчанию:

| Логин | Пароль | Роль |
|---|---|---|
| `admin` | `admin123` | все разделы |
| `operator` | `operator123` | заполнение справок своего учреждения |

После `npm run build` веб-интерфейс раздаётся самим API: http://127.0.0.1:8000

## Docker

```bash
cd spravka
docker compose up --build
```

Приложение: http://127.0.0.1:8000

## Android APK

Исходники: `spravka/android`

Сборка (нужны JDK 17+ и сеть):

```bash
cd spravka
bash build-apk.sh
```

APK: `android/app/build/outputs/apk/debug/app-debug.apk`

В приложении укажите адрес сервера, например `http://192.168.0.10:8000` (IP компьютера в той же сети). На эмуляторе Android: `http://10.0.2.2:8000`.

Если APK уже собран, его можно скачать с сервера: `/api/apk`.

## API

- `POST /api/auth/login`
- `GET /api/bootstrap` — анкета, учреждения и справочники для мобильного кэша
- `POST /api/sync` — выгрузка офлайн-справок (`client_uuid` защищает от дублей)
- `GET /api/reports/{id}/document.pdf`
- `GET /api/reports/{id}/document.docx`

Данные SQLite: `spravka/data/spravka.db`
