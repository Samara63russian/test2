# Информационно-аналитическая система сводных справок и опросных листов («СводСправка»)

Полнофункциональное программное решение для проведения аудитов и обследований учреждений, заполнения опросных листов (вопросов и ответов), автоматического формирования сводных справок и заключений с выгрузкой в официальные форматы (PDF, DOCX, Excel), аналитической панелью, справочниками и мобильным клиентом Android (APK) с поддержкой офлайн-работы.

---

## 🚀 Основные возможности системы

1. **Главная страница (Реестр справок и выбор учреждений)**:
   - Выбор конкретного учреждения из справочника либо общий просмотр всех объектов.
   - Фильтрация по отраслям (Здравоохранение, Образование, Соцзащита, Культура, Госуслуги) и датам проведения проверок (с / по).
   - Быстрый текстовый поиск по названию, номеру акта, ФИО проверяющего эксперта.
   - Детальный интерактивный просмотр протокола обследования с таблицей ответов, сводным заключением и рекомендациями.

2. **Заполнение опросных листов (Форма вопросов и ответов)**:
   - Структурированный опросник с группировкой вопросов по разделам (Пожарная безопасность, Санэпидрежим, Доступная среда, Документация, МТО).
   - Разнообразные типы ответов: логические (Да/Нет), шкала оценки (1–5), выбор из списка вариантов, числовые и текстовые поля.
   - Автоматический расчет итогового процента соответствия и выявление нарушений.
   - Поля для ввода сводного резюме и предписаний руководителю.

3. **Справочники и Настройки системы**:
   - **Справочник учреждений**: создание, редактирование, удаление учреждений, контактных данных (адрес, руководитель, телефон, email).
   - **Настройка вопросов и разделов**: создание новых критериев проверки, формулировок вопросов, весовых коэффициентов, типов полей и вариантов ответов.
   - **Управление пользователями**: создание логинов и паролей инспекторов и аналитиков, настройка ролей доступа (`admin`, `inspector`, `viewer`).

4. **Аналитическая панель**:
   - Ключевые показатели: общее число учреждений, проведенных обследований, средний балл качества.
   - Круговая диаграмма распределения проверок по отраслям.
   - График динамики проверок и среднего балла по месяцам.
   - Рейтинг лучших учреждений (Топ-5 лидеров).
   - Мониторинг системных нарушений и часто выявляемых замечаний.

5. **Генерация и скачивание документов**:
   - 📄 **PDF-справка**: официальный фирменный бланк с реквизитами, таблицей результатов, оценкой соответствия и местами для подписей.
   - 📝 **Word-документ (DOCX)**: редактируемая информационно-аналитическая справка.
   - 📊 **Excel-ведомость (XLSX)**: сводный реестр всех обследований для дальнейшего анализа.

6. **Мобильное приложение для Android (APK)**:
   - Режим **100% Offline-First**: локальное хранилище опросников и учреждений для заполнения на выездах без интернета.
   - Пакетная синхронизация с сервером (`/api/sync/batch`) при появлении сети (Wi-Fi/4G).
   - Готовый скомпилированный APK-пакет, доступный для скачивания прямо из интерфейса веб-приложения.

---

## 🛠️ Стек технологий

- **Backend**: Python 3.12, FastAPI, SQLAlchemy 2.0, Pydantic v2, ReportLab (PDF), python-docx (DOCX), openpyxl (XLSX), PyJWT, Passlib (PBKDF2-SHA256).
- **Frontend**: React 18, Vite, Tailwind CSS, Lucide Icons, Recharts, Axios.
- **Android**: Android SDK (Java/Kotlin Manifest & DEX architecture, Offline-First SQLite sync schema).
- **База данных**: SQLite (с возможностью переключения на PostgreSQL через `DATABASE_URL`).

## 📦 Запуск проекта

### 1. Запуск Backend API
```bash
cd backend
python3 -m pip install -r requirements.txt
python3 -m uvicorn main:app --host 0.0.0.0 --port 8000
```

### 2. Запуск Frontend
```bash
cd frontend
npm install
npm run dev
```
Веб-приложение будет доступно по адресу: `http://localhost:5173` (или `http://localhost:8000` при едином развертывании).

### 3. Сборка APK для Android
```bash
cd android
python3 build_apk.py
```
Сгенерированный файл: `apk/svod_spravka_inspector_v1.0.apk`.
