# Конспект — трекер запросов КП

Веб-приложение в папке [`konspekt`](./konspekt): отслеживание входящих писем с запросами коммерческих предложений, перечней и обычных запросов. Бесплатный ИИ кратко конспектирует письмо и создаёт запись.

```bash
cd konspekt && npm install && npm run dev
```

Подробности: [konspekt/README.md](./konspekt/README.md).
