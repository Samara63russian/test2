# Briefly — входящие запросы

Streamlit-приложение для обработки входящих писем от клиентов. Briefly помогает быстро увидеть
запросы на коммерческое предложение, перечни товаров и обычные вопросы, а затем сохраняет короткую
структурированную запись по каждому обращению.

## Возможности

- бесплатный локальный анализ без API-ключей и передачи текста письма во внешний AI-сервис;
- автоматическая классификация: `КП`, `Перечень` или `Запрос`;
- выделение краткого конспекта, товаров, количества, срока и приоритета;
- inbox с фильтрами, статусами и карточкой записи;
- добавление письма вручную для анализа;
- внутренние заметки и разделы `Записи` / `Настройки`;
- демонстрационные входящие для запуска без подключения почтового ящика.

## Запуск

```bash
pip install -r streamlit_app/requirements.txt
streamlit run streamlit_app/app.py
```

Сейчас источник писем работает в demo-режиме. Следующий интеграционный шаг — подключить IMAP или
OAuth-провайдера через переменные окружения и заменить `demo_emails()` на polling входящих писем.
