# КП Радар

Веб-приложение для отдела продаж: собирает входящие письма с запросами,
определяет тип и приоритет обращения, составляет краткое резюме и создаёт
рабочую карточку.

## Возможности

- единая лента запросов КП, цен, тендеров и документов;
- бесплатный локальный анализ без внешнего API;
- опциональная интеграция с локальной [Ollama](https://ollama.com/);
- получение непрочитанных писем по IMAP;
- AI-резюме, дедлайн, следующий шаг и приоритет;
- статусы «Новый», «В работе», «Обработан»;
- аналитика и адаптивный интерфейс.

## Запуск

```bash
npm install
npm run build
npm start
```

Приложение откроется на `http://localhost:3000`.

Для разработки запустите API и Vite в двух терминалах:

```bash
npm run server
npm run dev
```

## Подключение почты

Скопируйте `.env.example` в `.env` и заполните параметры IMAP. Для Gmail,
Яндекс Почты и других сервисов рекомендуется использовать отдельный пароль
приложения.

```env
IMAP_HOST=imap.example.com
IMAP_USER=sales@example.com
IMAP_PASSWORD=app-password
```

Пароль используется только сервером и не отправляется в браузер. Без
подключённой почты можно вручную вставлять письма через кнопку
«Добавить запрос».

## AI-режимы

По умолчанию работает встроенный локальный анализатор: он не требует ключей,
не имеет лимитов и не передаёт письма третьим лицам. Для генеративных резюме
можно подключить локальную Ollama:

```env
OLLAMA_URL=http://localhost:11434
OLLAMA_MODEL=qwen2.5:3b
```

Если Ollama недоступна, приложение автоматически использует встроенный режим.
