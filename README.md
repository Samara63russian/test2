A Streamlit webapp for the mobile game Star Wars: Galaxy of Heroes to monitor guild performance and activity. WIP

## Письмо → Запись (`email-inquiry-tracker/`)

Веб-приложение для отслеживания входящих писем с запросами КП / перечня / общими обращениями.

- Бесплатный локальный ИИ-конспект (без ключей)
- Опционально Groq (бесплатный API-ключ)
- Журнал записей в браузере

```bash
cd email-inquiry-tracker && npm install && npm run dev
```
