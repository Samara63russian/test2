# «Сводка» — справки учреждений

Веб-система и Android-приложение для заполнения, хранения и анализа
периодических справок учреждений.

## Возможности

- главная страница с фильтрами по учреждению и датам;
- конструктор вопросов: текст, число, дата, «да/нет» и варианты ответа;
- заполнение и просмотр справок, сохранение черновиков;
- выгрузка итоговой справки в DOCX;
- справочник учреждений с адресами и контактами;
- управление пользователями, паролями, ролями и доступом к учреждениям;
- аналитика охвата, динамики и активности учреждений;
- адаптивный PWA-интерфейс;
- Android-приложение на Capacitor;
- локальная очередь справок без интернета и автоматическая синхронизация;
- защита от повторной отправки одного офлайн-документа.

## Быстрый запуск

### Docker

```bash
export INITIAL_ADMIN_PASSWORD='сложный-пароль'
docker compose up --build
```

Приложение откроется на `http://localhost:8000`.

### Python

```bash
python3 -m pip install -r requirements.txt
export INITIAL_ADMIN_PASSWORD='сложный-пароль'
uvicorn reporting_app.main:app --host 0.0.0.0 --port 8000
```

При первом запуске создаётся администратор:

- логин: значение `INITIAL_ADMIN_USERNAME` или `admin`;
- пароль: значение `INITIAL_ADMIN_PASSWORD` или `Admin123!`.

Пароль по умолчанию предназначен только для локального ознакомления. На
сервере обязательно задайте собственный пароль до первого запуска.

База SQLite хранится в `data/reporting.db`. Путь можно изменить переменной
`REPORTING_DB_PATH`. Для резервной копии сохраняйте файл базы вместе с
`-wal`/`-shm` файлами либо предварительно остановите приложение.

## Роли

- **Администратор** — все справки, аналитика и настройки.
- **Оператор** — создание и просмотр справок назначенного учреждения.
- **Наблюдатель** — просмотр и выгрузка, без доступа к настройкам.

## Android

Нативный проект находится в `android/`. Перед сборкой установите Android SDK и
задайте `ANDROID_HOME`, затем выполните:

```bash
npm install
npm run android:apk
```

Отладочный APK будет создан по пути:

```text
android/app/build/outputs/apk/debug/app-debug.apk
```

На экране входа Android-приложения раскройте «Адрес сервера для Android» и
укажите публичный HTTPS-адрес веб-системы. После первого успешного входа
справочник учреждений и форма вопросов доступны без сети. Заполненные офлайн
справки хранятся на устройстве и отправляются после подключения.

Для публикации в магазине необходимо создать release keystore и собрать
подписанный AAB/APK стандартными средствами Android Studio. Сервер для
эксплуатации должен работать по HTTPS.

## API

После запуска интерактивная документация доступна на `/docs`. Сеансы API
передаются как Bearer-токены. Пароли хешируются PBKDF2-SHA256 с индивидуальной
солью, удаление вопросов и учреждений выполняется через архивирование, чтобы
не нарушать историю справок.

Папки `streamlit_app/` и `swgoh_comlink_fetcher/` относятся к прежнему
демонстрационному проекту и не используются системой «Сводка».
