# Сводные справки (новое приложение)

Полное приложение для форм вопросов/ответов и сводных справок находится в каталоге **`spravka-app/`**.

```bash
cd spravka-app
./run.sh
# http://127.0.0.1:8000
# admin / admin123
```

Android APK: `spravka-app/dist/spravka-debug.apk` (сборка: `./scripts/build-android.sh`).
