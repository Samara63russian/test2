# 🚀 EmailAI Request & RFQ Tracker (Трекер входящих писем и КП с бесплатным ИИ)

Веб-приложение для автоматического отслеживания, классификации и конспектирования входящих писем с запросами на коммерческое предложение (КП / RFQ), спецификаций / перечней номенклатуры или общих обращений, с автоматическим созданием структурированных записей в CRM-системе.

## 🌟 Основные возможности

### 1. 🤖 Умный бесплатный ИИ-движок (Free AI Engine)
* **Встроенный 100% бесплатный NLP-движок** (работает офлайн, без внешних API-ключей и задержек):
  * **Автоматическая категоризация писем**:
    * 📑 *Запрос на коммерческое предложение (КП / RFQ)*
    * 📋 *Запрос перечня / спецификации / номенклатуры*
    * 💬 *Общий запрос / консультация*
    * 📦 *Прямой заказ / Счёт на оплату*
    * 🚫 *Информационное / Спам / Рассылка*
  * **Извлечение структурированных сущностей**:
    * Название компании (ООО, АО, ИП, ЗАО, LLC) и ИНН/КПП.
    * ФИО контактного лица, телефоны, email-адреса, город и адрес доставки.
    * Таблица запрашиваемых позиций с количеством, единицами измерения (шт, м, кг, компл) и артикулами.
    * Оценка срочности (`Срочно (ASAP)`, `Стандартно`, `Низкий`) и расчет дедлайна.
  * **Генерация краткого конспекта (Executive Summary)** в 2–3 предложениях.
  * **Формирование списка следующих шагов (Action Items)** для менеджера.
  * **Автогенерация делового проекта ответа клиенту**.
* **Поддержка внешних бесплатных LLM-провайдеров**:
  * **Groq API** (Llama 3.3 70B Versatile — бесплатный тариф).
  * **Google Gemini API** (Gemini 2.0 Flash / 1.5 Flash — бесплатный ключ).
  * **OpenRouter** (бесплатные модели с суффиксом `:free`).
  * **Локальный Ollama** (`http://localhost:11434` с моделями `llama3`, `qwen2.5`, `mistral`).

---

### 2. 📥 Сбор и импорт входящих писем
* 📬 **Интеграция с IMAP**: прямое подключение к корпоративной почте (Yandex, Mail.ru, Gmail, Outlook, Exchange, собственный сервер) с автоопросом в фоне.
* 📄 **Загрузка файлов `.eml` / `.msg`**: парсинг RFC822 со всеми вложениями и заголовками.
* ✍️ **Быстрый ручной ввод / вставка текста** с мгновенным онлайн-предпросмотром результатов работы ИИ.
* 🎲 **Встроенный генератор реалистичных тестовых обращений** (1-клик для мгновенной демонстрации).
* 🔗 **Webhook API endpoint** (`/api/email/webhook`) для приема писем от внешних почтовых сервисов.

---

### 3. 📋 CRM-система и управление записями ("Создавать запись")
* 📊 **Канбан-доска (Kanban)** с этапами:
  * `Новый запрос` ➔ `В обработке` ➔ `КП готово` ➔ `Отправлено клиенту` ➔ `Сделка заключена (Успешно)` / `Отказ`.
* 📑 **Табличный вид (Data Grid)**: сортировка по любым колонкам, массовые действия (изменение статусов, удаление), раскрывающиеся строки с предпросмотром номенклатуры.
* 🗂️ **Лента карточек (Card Feed)**: удобный просмотр кратких ИИ-конспектов и ключевых позиций.
* 📈 **Аналитический дашборд**: воронка конверсии, распределение по категориям и срочности, объемы пайплайна, активность менеджеров, статистика точности ИИ.
* 📝 **Встроенный генератор официального коммерческого предложения (КП)**:
  * Интерактивный калькулятор спецификации, расчет скидок, НДС 20% и доставки.
  * Формирование официального бланка КП на корпоративном бланке, готового к печати / экспорту в PDF (`Ctrl+P`).
* 📤 **Экспорт**: выгрузка в **Excel / CSV** и резервное копирование в **JSON**.

## 🚀 Быстрый старт

### 1. Установка зависимостей и сборка
```bash
# Установка зависимостей backend
cd server && npm install

# Установка зависимостей frontend и сборка
cd ../client && npm install && npm run build
```

### 2. Запуск приложения
```bash
# Запуск единого сервера (раздает API и React Frontend на порту 3000)
cd /workspace && npm start
```
Приложение откроется по адресу: **`http://localhost:3000`**

### 3. Режим разработки (с Hot Reloading)
```bash
# Терминал 1: Backend
npm run server

# Терминал 2: Frontend (Vite)
npm run client
```

## 📡 Основные API Endpoints

| Метод | Endpoint | Описание |
|---|---|---|
| `GET` | `/api/requests` | Список запросов с фильтрацией по категории, статусу, срочности, поиску |
| `POST` | `/api/requests` | Создание новой записи с автоматическим анализом ИИ |
| `GET` | `/api/requests/:id` | Детальная информация по запросу + журнал активности |
| `PUT` | `/api/requests/:id` | Обновление полей, статуса, менеджера, заметок |
| `POST` | `/api/requests/:id/generate-quote` | Расчет и генерация официального коммерческого предложения |
| `POST` | `/api/requests/:id/send-reply` | Отправка сформированного ответа клиенту |
| `POST` | `/api/requests/seed-samples` | Перезагрузка демонстрационных запросов |
| `POST` | `/api/requests/generate-sample` | Генерация случайного входящего запроса для теста |
| `GET` | `/api/requests/export/csv` | Экспорт в CSV / Excel |
| `POST` | `/api/email/fetch-imap` | Запуск немедленного сбора почты по IMAP |
| `POST` | `/api/email/upload-eml` | Загрузка и анализ `.eml` файла |
| `GET` | `/api/analytics/dashboard` | Метрики, воронка и распределения |
| `GET` | `/api/events` | SSE поток для синхронизации в реальном времени |
