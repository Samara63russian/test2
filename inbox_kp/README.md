# Конспект — входящие запросы КП

Веб-приложение для отдела продаж: входящее письмо разбирается, ИИ (или встроенный разбор) кратко конспектирует его и создаёт карточку.

Типы карточек:

- **Запрос КП** — просят коммерческое предложение, котировку, RFQ
- **Перечень / прайс** — просят каталог, номенклатуру, наличие
- **Запрос** — уточнение по срокам, отгрузке, документам
- **Другое** — рассылки и нецелевые письма

## Что умеет

1. Вставить текст письма (в том числе скопированный из Outlook/Gmail, с полями «От» и «Тема»).
2. Загрузить файл `.eml`.
3. Забрать непрочитанные письма по IMAP (Gmail — через пароль приложения).
4. Собрать конспект: кто пишет, что нужно, срок, следующий шаг.
5. Вести статус: новый → в работе → КП отправлено → закрыто.

## Бесплатный ИИ

По умолчанию работает **без ключа** — встроенный разбор по тексту письма.

Чтобы конспект стал «человеческим», в настройках укажите бесплатный ключ:

1. [Groq](https://console.groq.com/keys) — модель `llama-3.1-8b-instant` (рекомендуется)
2. Google Gemini Flash — альтернатива
3. Любой OpenAI-совместимый URL (Ollama на своей машине, OpenRouter и т.п.)

Ключ можно также задать переменной окружения `GROQ_API_KEY`.

## Запуск

```bash
cd inbox_kp
python3 -m pip install -r requirements.txt
python3 run.py
```

Откройте http://127.0.0.1:8765

Кнопка **Демо** загружает шесть типичных писем (КП, прайс, простой запрос, тендер, каталог, рассылка).

```bash
cd inbox_kp
python3 -m pytest -q
```

Данные хранятся локально в `inbox_kp/data/inbox.db`.
