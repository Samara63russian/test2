# Конспект

Веб-приложение для учёта входящих писем с **запросами коммерческого предложения (КП)**, **перечнями** и обычными **запросами**. Бесплатный ИИ кратко конспектирует письмо и создаёт карточку-запись.

## Возможности

- Вставка письма (поля или сырой текст `From` / `Subject`)
- Автоопределение типа: КП / перечень / запрос / прочее
- Краткий конспект + ключевые пункты, срок, позиции, компания
- Статусы: новое → в работе → КП отправлено → закрыто
- Поиск и фильтры
- Демо-письма для быстрого старта
- **Бесплатно без ключей** (локальный анализатор) или точнее через бесплатные [Groq](https://console.groq.com/keys) / [Gemini](https://aistudio.google.com/apikey)

## Запуск

```bash
cd konspekt
npm install
npm run dev
```

Откройте [http://localhost:3000](http://localhost:3000).

Опционально в `.env.local`:

```env
GROQ_API_KEY=gsk_...
GEMINI_API_KEY=AIza...
```

Ключи также можно ввести в интерфейсе (кнопка «ИИ и ключи») — они хранятся только в браузере.
